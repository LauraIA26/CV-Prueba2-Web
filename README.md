# Portfolio de Laura Jiménez

## Ejecución local

**Requisito:** Node.js 22.12 o posterior.

1. Instala las dependencias con `npm install`.
2. Inicia el servidor de desarrollo con `npm run dev`.
3. Abre <http://localhost:3000>.

No se necesita configurar una clave de Gemini para ejecutar este portfolio.

Para comprobar la compilación de producción, ejecuta `npm run build`. Para
previsualizarla localmente, ejecuta `npm run preview`.
